# Mama Wallet illustration and brand assets

Original illustrations generated for this project, using the first family scene as the character and style reference. The user requested illustrations throughout suitable app screens and application of the generated logo. These illustrations supersede the earlier floating-icon decoration on onboarding and pairing; Hugeicons remain the functional UI icon set.

| Asset | Placement |
| --- | --- |
| family-ready.webp | Welcome and wallet-created confirmation |
| family-connect.webp | Parent pairing landing and pairing-link waiting sheet |
| family-help.webp | Elder Help and family-request confirmation |
| wallet-care.webp | Empty Elder/Family activity and successful demo funding |

Illustrations use responsive contained dimensions, decorative empty alt text alongside explanatory headings, and WebP exports with transparency. Payment amounts, keypad, review checks, approval controls and stopped-payment screens remain focused on their functional state.

The generated wordmark is installed in the header. The matching app mark supplies 16/32/48px ICO, 32px PNG favicon, 180px Apple touch icon and 192/512px maskable install icons. All files are served locally and included in service-worker shell cache v6. Unused large source PNGs were removed and the runtime illustrations are compressed WebP; no third-party reference artwork is reused.
